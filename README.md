# 🖱️ Cursor Draw

> Программа для рисования текста на экране через эмуляцию мыши.
> Печатаешь на клавиатуре — курсор сам рисует буквы в активном окне
> (Paint, Photoshop, GIMP, блокнот и т.п.).

---

## 📖 Описание

**Cursor Draw** превращает ввод с клавиатуры в рисунок на экране.
Каждой букве, цифре и знаку соответствует набор штрихов (векторный глиф),
который программа «прорисовывает» мышью в заданной области экрана.

Работает поверх любого графического редактора:

- рисует буквы по одной в клетку, как в текстовом редакторе;
- автоматически переносит на новую строку, когда строка заканчивается;
- умеет рисовать отдельные глифы **на всю область** (по спец. клавишам);
- все настройки и формы символов вынесены в отдельные файлы —
  перекомпиляция не нужна.

---

## 🎮 Управление

| Клавиша           | Действие                                                    |
|-------------------|-------------------------------------------------------------|
| `Enter`           | Включить режим рисования (каретка в левый верх области)     |
| `Backspace`       | Выключить режим рисования (Ctrl отпускается)                |
| `Shift` + `Enter` | **Выход из программы**                                      |
| `Shift`           | Показать координаты курсора мыши (для настройки области)    |
| `Tab`             | Перейти на новую строку                                     |
| `Esc`             | Ничего не делает                                            |
| Буквы / цифры / пробел | Рисуются в клетку по мере нажатия                      |
| `all_area_keys`   | Клавиши из `config.txt`, рисующие глиф на всю область       |

### Как это выглядит в работе

1. Запускаешь `.exe`.
2. Открываешь редактор (Paint, Photoshop, …) и переключаешься в него.
3. Нажимаешь `Enter` — режим включён, в консоли `[ON]`.
4. Печатаешь текст — он появляется на холсте.
5. Нажимаешь `Tab` — новая строка.
6. Нажимаешь `Backspace` — режим выключен.
7. Нажимаешь `Shift` + `Enter` — выход.

## ⚙️ Конфигурация

Все параметры хранятся в `config.txt` рядом с программой.
Редактируются без перекомпиляции — просто меняешь файл и перезапускаешь.

### Область рисования

| Параметр    | Описание                          |
|-------------|-----------------------------------|
| `area_x1`, `area_y1` | Левый верхний угол области |
| `area_x2`, `area_y2` | Правый нижний угол области |

### Размеры

| Параметр    | Описание                                                    |
|-------------|-------------------------------------------------------------|
| `char_w`    | Ширина клетки (шаг каретки по горизонтали)                  |
| `char_h`    | Высота клетки (шаг каретки по вертикали)                    |
| `glyph_w`   | Фактическая ширина буквы (`< char_w` даёт зазор между буквами) |
| `line_gap`  | Отступ между строками                                       |

### Скорости (в миллисекундах)

| Параметр           | Описание                              |
|--------------------|---------------------------------------|
| `px_delay_ms`      | Пауза между пикселями (главный тормоз) |
| `hover_delay_ms`   | Пауза перед нажатием ЛКМ              |
| `after_down_ms`    | Пауза после нажатия ЛКМ               |
| `before_up_ms`     | Пауза перед отпусканием ЛКМ           |
| `stroke_gap_ms`    | Пауза между штрихами                  |

### Логика

| Параметр         | Описание                                                        |
|------------------|-----------------------------------------------------------------|
| `use_ctrl`       | Зажимать Ctrl на время рисования (`1` — да, `0` — нет)          |
| `all_area_keys`  | Клавиши, при которых глиф рисуется **на всю область**           |

## 🏗️ Сборка на Windows

## 1. Устанавливаем тулчейн

```rust
rustup toolchain install stable-x86_64-pc-windows-gnu
rustup default stable-x86_64-pc-windows-gnu
```

## 2. Устанавливаем MinGW-w64 (через msys2)

```rust
pacman -S mingw-w64-x86_64-gcc
```

## 3. Добавляем C:\msys64\mingw64\bin в PATH

## 4. Клонируем репозиторий в удобную директорию

```bash
git clone https://github.com/birlurnou/cursor_draw.git
```

```bash
cursor_draw/
├── Cargo.toml        # конфигурация проекта и зависимости
├── config.txt        # настройки области, размеров, скоростей
├── glyphs.txt        # векторные описания символов
└── src/
    └── main.rs       # исходный код
```

## 5. Сборка (cmd в директории программы)

```rust
cargo build --release
```

#### Готовый .exe появится в target\release\cursor_draw.exe
